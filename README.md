\# Siemens Climatix IC (RDS110) Home Assistant Integration



Custom Home Assistant integration for controlling the Siemens RDS110 Smart Thermostat via the Siemens Climatix IC cloud platform.



\## Features

\- \*\*Climate Entity\*\*: Full target setpoint control ($6.5^\\circ\\text{C}$ – $35.0^\\circ\\text{C}$) and HVAC Mode toggling (HEAT / OFF).

\- \*\*Dual Zone Switch Control\*\*: Independent control for \*\*Zone 1 (Hot Water)\*\* and \*\*Zone 2 (Space Heating)\*\*.

\- \*\*Sensors\*\*: Room Temperature, Target Setpoint, Setpoint Offset, Relative Humidity, and Operating Mode.

\- \*\*Dynamic Plant ID Discovery\*\*: Automatically discovers your thermostat instance upon login.



\## Installation via HACS



1\. Open HACS in Home Assistant.

2\. Click the 3 dots in the top right corner and select \*\*Custom repositories\*\*.

3\. Add the URL of this repository, select \*\*Integration\*\* as the category, and click \*\*Add\*\*.

4\. Search for \*\*Siemens Climatix IC RDS110\*\* and click \*\*Download\*\*.

5\. Restart Home Assistant.

6\. Go to \*\*Settings\*\* $\\rightarrow$ \*\*Devices \& Services\*\* $\\rightarrow$ \*\*Add Integration\*\* $\\rightarrow$ search for \*\*Siemens Climatix IC RDS110\*\*.

7\. Enter your Climatix IC Email and Password.
